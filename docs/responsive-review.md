# 반응형 검증 기록

2026-09-07. 기존 디자인을 유지하며 화면 폭에 따른 읽기와 조작 문제를 수정했습니다.

## 변경 내용

- 상세·저장 화면의 모바일 탐색 헤더를 메인 화면과 맞췄습니다.
- 관리자 화면에 모바일 메뉴를 추가하고 입력창·버튼·목록의 줄바꿈을 조정했습니다.
- 작은 화면에서는 AI 차트의 막대를 별도 행에 배치하고 가격·지능 값을 표로 제공합니다.
- 모바일 페이지 이동은 이전·다음 버튼과 현재 위치를 표시합니다.
- 초광폭 화면의 본문 폭을 제한하고 주요 버튼의 터치 영역을 넓혔습니다.
- 상세·카드의 초기 숨김 애니메이션을 제거해 첫 렌더부터 내용을 읽을 수 있게 했습니다.

## 검증 범위

Chromium에서 공개·관리자 15개 화면을 320, 390, 640, 768, 844, 1024, 1280, 1440, 1920, 2560px 폭으로 검사했습니다. 높이는 900px이며 844px 폭에서는 390px 높이로 가로 화면을 검사했습니다.

150개 조합에서 문서 가로 넘침, 의도하지 않은 콘텐츠의 화면 밖 배치, 처리되지 않은 페이지 오류가 검출되지 않았습니다. 코드 블록과 탐색 메뉴의 의도된 가로 스크롤은 제외했습니다. 콘솔 경고 전체가 없다는 의미는 아닙니다.

추가로 160개 기사 예시의 페이지 이동과 끝 페이지 경계, 차트 4개 지표 전환, 빈 검색 결과 복구, 긴 코드의 내부 스크롤, 관리자 메뉴 이동과 자동 닫힘, RSS·영상 요청 실패 표시, 입력 보존, 로그아웃을 확인했습니다.

웹 전체 테스트 335개를 통과한 후 현재 페이지 안내 회귀 테스트를 추가했고, 해당 파일 9개 테스트를 다시 통과했습니다. 최종 소스의 타입 검사와 변경 파일 27개의 Biome 검사도 통과했습니다.

```sh
pnpm --filter @devbrief/web test
```

테스트 실행 환경은 Node.js 22입니다. 상세 검사 집계는 [검증 결과](responsive-check-results.json)에 있습니다.

## 제한

실제 단말기, Safari/iOS, 운영 API의 성공 응답과 실제 YouTube 재생은 이번 검사 대상에 포함되지 않았습니다. WebKit 실행은 시스템 라이브러리 `libwoff2dec.so.1.0.2` 부재로 실패했습니다. 관리자 오류 처리는 쓰기를 거절하는 로컬 예시 API로 확인했습니다.
